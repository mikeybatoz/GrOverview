# GrOverview

Plants, spaces and live readings. Journaling, room layouts and device controls in Home Assistant, installed through its Add-on Store.

[![Open GrOverview in Home Assistant](https://my.home-assistant.io/badges/supervisor_app.svg)](https://my.home-assistant.io/redirect/supervisor_app/?app=572737a2_growerview&repository_url=https%3A%2F%2Fgithub.com%2Fmikeybatoz%2FGrOverview)

Experimental development build. Open Web UI to install the bundled Home Assistant connector. No HACS required. Existing records remain in Home Assistant; see DOCS.md for backup and migration details.
